Cara Bermain

Pastikan browser diizinkan mengakses Kamera. Game ini membaca gerakan wajahmu!

Miringkan kepalamu ke KIRI atau KANAN secara perlahan untuk memilih jawaban yang sesuai di layar.

Tahan posisimu selama ±1 detik hingga bar hijau terisi penuh untuk mengunci jawaban.

Raih Skor Target secepatnya. Untuk mode 2 pemain, layar akan dibagi dua secara otomatis!
